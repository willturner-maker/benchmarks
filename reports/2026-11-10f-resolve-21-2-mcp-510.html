What 5.1.0 changed that trials paid for — or caught

Three record_frame semantics

create_variant_from_ranges treats explicit record_frame as raw-absolute — one T3 trial’s items landed before the timeline start (issue-#164 shape), caught by its own read-back, rebuilt. append_to_timeline is start-relative and its record_frame_mode:"absolute" is inert. ripple_insert is start-relative; its dry-run plan exposes the absolute landing frame pre-mutation.

Render keys, gate-broken reader

set_settings silently ignores ResolutionWidth/Height — FormatWidth/Height are the live keys (one trial caught it from job metadata and rebuilt the job). render.get_settings is version-gate-broken on this build; substitute probe_render_settings or queued-job metadata.

Linking & selectors

set_property("Linked") now refuses with success:false (loud, not silent); set_clips_linked + get_linked_items is the working route. timeline_item accepts timeline_name (pinned:true + restore) — but unpinned reads still hit a co-agent’s current; one T7 trial discarded four such reads and said so.

Fusion scope proven two ways

fusion_comp’s timeline_item_id resolves against the current timeline (ignores timeline_id): a mid-run switch produced a clean ITEM_NOT_FOUND, and the trial proved non-contamination by probing the co-agent’s timeline (comp_count 0) plus the official bridge server’s GetFusionCompCount()==1 — first cross-interface T8 pass.

Surface move

append_to_timeline now lives on media_pool, not the timeline tool — the operator hit this building the fixture; agents saw it only as a valid-actions list. action_help still has gaps (ripple_insert: HELP_NOT_REGISTERED).

Safety nets seen live

Built-in before/after read-back verification on appends; RENDER_PRESET_STATE_INHERITED on every prepared job; timeline.duplicate auto-restoring the hijacked current pointer; confirm-token gating with a names preview; C6 _archived_vNN siblings on every mutation — again the zero-mutation proof for T1.

Method & deviations

  • Hard seal — the operator’s memory dir, this repo, and the prior wave’s off-repo findings were moved off-disk before launch and restored after scoring; agent type has MCP tools only.
  • Deviation — this suite’s sealed agents have no shell at all, so the operator pre-created the three T7 target dirs (replacing prior waves’ one-mkdir amendment). Dirs were empty at launch.
  • Grading used pinned read-backs only (probe / get_items / get_track_* / get_comp_count / my own ffprobe of each T7 file, bytes matching the agents’ reported figures); operation log for ordering only.
  • No operator Resolve call of any kind until every agent in each wave had reported (rule inherited from (e), honored across all nine waves).
