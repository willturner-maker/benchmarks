What changed under the hood

Ripple inserts can pin

ripple_insert honors timeline_name/timeline_id on dry-run and executing calls — immune to the current-timeline race that mis-bound inserts in both prior benchmarks.

Fusion scope traps, live

Bare-param timeline_item_fusion calls execute against the current timeline (one agent polluted a foreign timeline, repaired it, self-reported). The separate fusion_comp tool ignores timeline_id entirely.

Marker break absorbed

21.2's raw-API AddMarker duration break never surfaces through the 4.19.0 wrapper — three agents, zero failed calls, duration defaults to 1.

Broken / gone

DeleteFusionCompByName returns bare False on 21.2-created comps. GetProjectList removed. render.get_settings unavailable. A string media_type crashes the wrapper — pass 1/2.

Archive sweep

add_track now triggers the server's auto-archive too — teardown must delete *_archived_vNN rows alongside the timelines themselves.

DF arithmetic

29.97 DF source reads sit 1 frame low (src 2000 → 1999); durations are truth. A WAV's source rate freezes at the project rate on import — 121 source frames can span 151 timeline frames.

Methodology honesty

Contamination control was tightened mid-flight. Run-1 agents could read the operator's notes; one T8 agent grep-confirmed it had read prior-run lesson files before solving — that trial was discarded and replaced by a sealed re-run (46 uses / 343 s). From run 2 the environment was hard-sealed: memory directory and this benchmark's report moved off-disk during scoring, and every brief carried “MCP tools only, no shell or files.”

Wall times include shared-engine contention by design; run-3 wave 1 also absorbed the grader rebuilding preconditions live. One T7 agent burned its one-shot report on a “placeholder” and corrected it by message — the corrected report matched every read-back, so honesty stands; its 7285 ms render is excluded from throughput claims.

Cleanup evidence

Teardown after each run: project back to 1 timeline (bench-base bit-identical, item ids unchanged), render queue empty, all archives deleted. Kept renders: perf_probe_2026-11-05/{cold,warm,agbench1..3}/ — every file ffprobe-verified at 121 frames, h264, 3840×1520.
