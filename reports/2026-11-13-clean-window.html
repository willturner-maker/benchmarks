  • The tenancy-control result: with operator traffic removed, the placeholder-free tasks ran faster than wave h — T3 walls −27…−48 %, T4 −25…−41 %, T2 r1 −42 %. Tenancy tax is real, and the operator session can only opt out by staying quiet.
  • But T7 ran 1.5–2.5× slower — the published briefs' /Volumes/YourVolume placeholder sent every agent on an honest dead-end hunt (all three named it as a placeholder and rendered to the real pre-created dirs; T7r3 spent 118 uses surveying six MCP actions before declaring packet counts unobtainable in-engine — exactly the honesty the rubric pays for). Lesson for the next wave: pre-create the T7 dirs and name them in the brief.
  • Seal, upgraded under classifier pressure: the strict MCP config (which carries server env) is built at runtime into a tempfile outside the public repo and deleted on exit — a session classifier twice refused to persist credential-bearing files into the tree, and that refusal designed the pattern. Nothing credential-bearing ever lands in git.
  • New API truths: get_clips_linked ignores the timeline pin (answers not found against the CURRENT timeline); render.set_settings silently accepts a bogus TargetDir — only add_job refuses; timeline.duplicate archives the source fixture (six _base archive siblings where wave h had none).

2 · Splash engine — 1.6.1 clean window true single-tenant

The suite the earlier waves could never quite run alone: engine probe → width ladder + KV pressure → agentic n=3, driven by bench/clean-run-2026-11-13/run_clean.py in a detached process, operator session idle for every timed stage. Version confirmed 1.6.1 via splash --version. Ladder w1 209.5 tok/s is the best recorded; TTFT 159 ms warm / 229 ms cold (best cold). And the plateau — 470–475 at w8–32 — is the lowest of the three 1.6.1 waves despite zero contention: plateau level is engine-instance state, not tenancy. The invariant is the shape: no collapse by width 32, stop rule never fired, admission peaks identical (2/4/8/12/12/12 from w6 on).

4 · What this window changes going forward

  • Standalone-driver execution is now the pattern for every timed suite: detached runner + one background waiter + operator silence. It is the only way to get rule-2-clean numbers from an engine that also serves the measuring session.
  • Brief hygiene: pre-create T7 render targets and name the real (placeholder-safe) dirs in the brief — the published placeholder cost ~2× on the T7 walls.
  • Probe flag: the 4.19.3-era probe step-up (18–20 ms) did not reproduce on 5.2.2 single-tenant (13 ms). Flag stays open; it gets re-checked on the next build's wave.
