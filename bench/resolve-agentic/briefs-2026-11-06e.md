*Amendment disclosure:* the task text as first archived told the agent to create its own output
directory while the preamble forbade shell commands, and `render.prepare_render_job` does fail on a
missing `target_dir`. The one-command exception was added before dispatch and is a disclosed
deviation; file verification itself stays on the MCP side (`render.verify_output` probes the file),
and a `mkdir` cannot read prior findings, so the seal is unaffected.
